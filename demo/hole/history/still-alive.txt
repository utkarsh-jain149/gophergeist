Gopher is not quite dead

Gopher never disappeared. A small community still runs servers, often called
gopherholes or phlogs (Gopher blogs). Floodgap, run by Cameron Kaiser, has
been a hub for years and keeps a list of live servers.

Browsers mostly gave up on it. Firefox removed built-in Gopher support in
version 4, in 2011. But the text browser Lynx still speaks Gopher, and so does
curl: you can fetch a menu with a plain curl gopher:// command.

In 2019 a new protocol called Gemini was created, openly inspired by Gopher.
It keeps the simple, text-first spirit and adds encryption. Many people who
run gopherholes also run Gemini capsules.

To run your own hole, all you need is a folder of text files and a tiny
server. Port 70 is the traditional Gopher port.
